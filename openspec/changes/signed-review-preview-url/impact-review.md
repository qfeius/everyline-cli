# 影响评审：透传并展示签名审查预览链接

## 能力变化

本变更只消除 Skill 对签名预览 URL 的规则歧义，并用测试固化 CLI 既有透传行为；未新增远端能力。

## 回归风险

- Agent 若把签名 token 当作普通凭证脱敏，会再次产生不可访问链接。
- Agent 若单独提取 token，会扩大凭证暴露范围。
- Agent 若在链接缺失时自行拼接，会产生未经后端签发的无权限地址。

## 测试与验收

- 回归测试同时断言原始 `url` 和 `reviewDetailUrl` 与后端签名链接完全一致。
- Skill 校验确认 frontmatter、名称和引用结构有效。
- 全量 Go 测试覆盖现有命令与工作流兼容性。

## 发布与回滚

发布只需随 CLI 包同步 Skill；Codex、WorkBuddy 和豆包更新同版本 Skill 后生效。回滚仅涉及 Skill 文案和测试，不涉及后端或数据。
