# 审查清单对话分页规格增量

## Requirement: Skill 必须分页展示全部真实审查清单

EveryLine Skill MUST 完整读取 CLI 返回的所有清单分页，并以每页 4 个真实清单的方式展示，不得因宿主单次选项容量截断候选。

### Scenario: 清单超过一页

- **GIVEN** CLI 返回超过 4 个真实清单
- **WHEN** Skill 进入清单选择阶段
- **THEN** 每页必须展示最多 4 个真实清单
- **AND** 必须显示 `第 X/Y 页，已选择 N 项`
- **AND** 必须提供上一页、下一页、完成选择和按名称搜索

### Scenario: 用户跨页选择

- **GIVEN** 用户已在一页选择若干清单
- **WHEN** 用户切换到其它页面并继续选择
- **THEN** Skill 必须保留之前选择的真实清单 ID
- **AND** 全部页面必须继续使用首次完整查询建立的稳定全局编号

### Scenario: 用户输入未展示清单的完整名称

- **GIVEN** 目标清单存在于完整候选集合但不在当前页
- **WHEN** 用户输入该清单完整名称
- **THEN** Skill 必须在完整候选中匹配并加入选择
- **AND** 名称不唯一时必须展示可区分候选，不得猜测

## Requirement: 清单与立场方必须分为两个独立阶段

EveryLine Skill MUST 先完成清单选择，再通过新的独立交互完成立场方选择，不得把两类问题放入同一个选择卡片。

### Scenario: 清单尚未完成

- **GIVEN** 用户仍在浏览、搜索或选择清单
- **WHEN** Skill 准备下一次交互
- **THEN** 只能继续清单阶段
- **AND** 不得同时展示立场方问题

### Scenario: 清单完成

- **GIVEN** 用户选择“完成选择”且至少已有一个规则来源
- **WHEN** Skill 固化清单选择
- **THEN** 下一次独立交互必须进入立场方选择
- **AND** 最终任务参数中的清单 ID 必须来自完整候选映射
