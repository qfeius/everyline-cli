# 影响评审：审查清单对话分页

## 能力变化

本变更只调整 EveryLine Skill 的对话编排，不修改 CLI 或远端接口。用户可在 WorkBuddy 等宿主中分批浏览全部清单，并在清单完成后单独选择立场方。

## 潜在回归

- 清单不超过 4 项时仍拆分交互，会比原来多一次卡片，但消除了两个业务问题混排的歧义。
- 翻页后若编号或候选顺序变化，可能把显示名称映射到错误 ID。
- 名称重复时若直接按名称选中，可能产生歧义；必须继续展示区分信息。
- 用户未执行完成选择时进入立场方阶段，会丢失清单选择状态。

## 测试覆盖

- 场景矩阵覆盖单页、多页、前后翻页、跨页累计、全局名称搜索、重名和两阶段隔离。
- Skill 快速校验检查入口与引用结构。
- diff 检查确保文档格式正常。

## 发布与回滚

随下一版 CLI 包发布并重新安装 Skill 后，WorkBuddy 和豆包使用新流程；Codex 的项目软链接立即读取新规则。回滚仅恢复 Skill 与配套文档。

## 结论

可以进入实现。
